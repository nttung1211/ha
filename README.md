# ha

Agent skill for the Herdr desktop app: open agent panes (`/ha run`) and message them (`/ha send`).

## Install

```sh
npx skills add nttung1211/ha
```

## Usage

```
/ha run  <agent> <name> [-i [space/]tab] [-a dir] [-m model] [-e effort] [task]
/ha send <to> [-w] [-r] <text>
/ha man
```

See [man.md](man.md) for the full guide.
